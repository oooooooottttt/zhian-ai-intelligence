## 启动与停止

在项目目录启动：

```sh
python3 -m aicti_core serve --demo
```

访问 <http://127.0.0.1:8849/>。交接时演示服务正在该地址运行，只监听本机；使用独立的 `.data/system-demo.sqlite3`，不联网采集。停止后重新运行命令即可恢复；终端中按 `Ctrl+C` 停止。

演示撤回会持久保存。再次需要撤回前的有效公告时，先停止服务，再运行：

```sh
python3 -m aicti_core serve --demo --replay-demo
```

重放新增一份虚构有效修订，保留旧修订和回答，不删除历史。普通重启不会恢复已撤回公告。最新交接截图位于 [system-evidence.jpg](../screenshots/system-evidence.jpg)。

实际监测使用 `python3 -m aicti_core serve`；只查看已有真实数据使用 `python3 -m aicti_core serve --no-collect`。这两种模式默认使用 `.data/monitor.sqlite3`，与演示库分开。进程运行时执行监测与处理任务；停机期间没有后台持续采集。

## 尚需验收

1. 真实本地 Ollama 模型与向量模型的端到端行为、中文问答质量及延迟。本轮仅完成离线网关和工具循环测试，没有安装或下载模型，也没有实现云端 API。
2. 比赛要求的覆盖率、准确率与五秒时延，需要授权评测集和真实环境，不能由 393 项测试或虚构演示推断。
3. 生产标准/政策来源、POC 线索覆盖与更多组件版本格式。当前只支持明确的数字版本子集与精确枚举；条件不清或资料缺失保留未知。
4. 更大数据量的按依赖失效与范围检索。首版有明确容量上限，并保守地使所有派生实体随来源变更失效。

当前系统不会主动扫描资产、执行 POC、下载论文 PDF 或自动修改目标服务。清单是用户声明的快照，超过 24 小时失效；命中漏洞范围不表示已遭攻击。
