# 监测模块集成验证

日期：2026-09-30，Asia/Shanghai。以下为该次运行观察，不代表未来来源始终可用或全量覆盖。

## 真实采集

默认实时库 `.data/monitor.sqlite3` 已保存官方公开接口响应规范化后的证据。首次 30 天窗口结果：

| 来源 | 保存的来源记录 | 窗口完成 |
| --- | ---: | --- |
| NVD AI 组件关键词 | 98 | 是 |
| GitHub 全局 AI 依赖公告 | 28 | 是 |
| vLLM 公开仓库公告 | 26 | 是 |
| arXiv 安全论文查询 | 140 | 是 |
| OWASP GenAI 滚动订阅 | 10 | 是；来源并不提供完整 30 天历史 |

302 份来源记录经 CVE/GHSA 关联为 285 个事件，其中 248 个被当前规则标为 AI 相关，37 个保留供“全部采集结果”查阅。这些数量是首次采集/backfill，不是新增漏洞数量、风险数量、筛选准确率或时延指标。

另在隔离测试库验证 arXiv 每周期只允许一个请求：分页位置 50 → 100 → 当前窗口完成，去重得到 140 条。NVD/API 的小预算续传、撤回与异常回滚使用离线固定样例验证；没有人为制造远端真实漏洞、撤回或限流。

实时页面开启自动调度，NVD 每小时，GitHub 两个源每两小时，arXiv/OWASP 每六小时。关闭进程会停止调度；再次启动读取持久化位置。不能把配置轮询频率直接视为上游发布到发现的时延保证。

## 修复与回归

实采修复了 GitHub 不接受毫秒日期范围、仓库 next Link 省略默认过滤项，以及 arXiv 分页 feed 更新时间不同导致反复重扫的问题。NVD 检查结果总数与页边界，发生可检测漂移时重扫关键词而不推进完成窗口；上游没有一致性快照，极端同数量替换仍需要后续对账方案。

观察时间和采集路径不计为内容修订。真实版本、正文、编号关联、使用条件及撤回变更保留快照；不同来源的冲突证据保留，标题相似不自动合并。

`python3 -m unittest discover` 共 127 项离线验证通过，在 Python 3.12 和 3.14 环境通过。覆盖分页跨周期恢复、错误游标、额度耗尽、未知或不安全链接、DNS 私网/重绑定边界、响应大小与绝对截止时间、XML 实体、SQLite 事务回滚、别名桥接、版本/撤回、失败退避、中断恢复、上游日期排序与分页，以及本地页面 Host/Origin/token 边界。测试无需凭据或外部服务。

本地浏览器实际查看了真实数据和来源状态。正常本机请求可读；错误 Host、跨站请求、缺 token 和错误 Origin 返回 403，正确 Origin/token 的调度请求返回 202。页面使用文本节点呈现外部信息，且附来源链接、许可/修改说明与修订历史。JSON 导出实际完成 285 条。

## 当前边界

默认五个来源代表四种来源类别：漏洞库、厂商公告、论文、社区动态。不是五种类别，也不能据此声称达到赛题最高档覆盖。

NVD 最新特定条款网页在本次浏览核查时返回访问限制，未绕过；公开 API 实采正常。NIST 许可及 NVD 署名/非背书说明已保留，正式分发前仍需复核来源最新具体条件，详见 `SOURCE_POLICY.md`。

已见漏洞每窗口逐条核查的成本会随历史增长。首版使用窄组件范围；扩大到大量条目前，应将更新采集与历史核查拆为独立持久化队列，分别安排额度、到期时间和完成指标。RSS 过期或来源不提供的撤回无法仅靠 feed 判定。关键词和规则仍可能漏掉未知组件，后续接入与规则扩充需要复核来源许可。
